# Reference page topology

Reference: https://export-youtube-playlist.vercel.app/

The reference is a long-form utility landing page built around one conversion path: paste a YouTube playlist URL, choose output fields, and export. Its reusable structure is:

1. Compact navigation with product name and anchor links.
2. Above-the-fold two-column hero: benefit-led copy on the left, exporter form in a raised card on the right.
3. Trust/value strip explaining speed, privacy, and supported formats.
4. Use-case cards for creators, researchers, marketers, and archivists.
5. Step-by-step usage guide.
6. Field-customization explanation.
7. FAQ and official YouTube API explanation.
8. Footer with utility and legal links.

## Codex adaptation

The first release intentionally reduces breadth. It keeps the high-intent hero/tool pattern and supporting explanation, but limits the product to three outputs: CSV, XLSX, and copied watch links. Channel export, analyzers, extra extractors, and additional file formats are deferred.

## Responsive behavior

- Desktop: 12-column container; hero copy occupies five columns and exporter seven.
- Tablet: single-column hero with exporter directly below the headline.
- Mobile: 16px page gutters, full-width controls, horizontal preview table, sticky-feeling primary action within the card.

## Visual direction

- Original visual system: ink/navy text, warm white background, electric coral-red actions, pale blue/lavender supporting surfaces.
- Rounded but not bubbly: 16-24px cards, 10-12px controls.
- High contrast and restrained shadows. The page should feel like a focused professional utility, not a generic template.
