## 元信息与标题结构

AITDK Description 原文：`Übertragen Sie Ihre YouTube-Lieblingsmusik zu Ihrem Export to file-Konto`。它把文件导出套进账号迁移模板，但正文步骤明确写 `kein Zielkonto erforderlich`。AITDK 此次显示 Canonical **Missing**；仅表示本次工具观察，不延伸为整个站的索引结论。

三个 H2 依次是：

1. Unterstützung für alle Musikplattformen
2. Wie exportiere ich eine YouTube-Wiedergabeliste in eine CSV- oder TXT-Datei?
3. Wichtige Informationen zum Transfer von YouTube zu Export to file

H3 包含三个步骤、完整报告、功能总览与六个功能名、热门转换、帮助；H4 为可转移范围。完整原文见 [AITDK 标题记录](./原始数据-2026-10-25/TuneMyMusic-headings-AX.txt)。

## 实际入口与功能边界

点击 `Lass uns starten` 后进入 `/de/transfer`，先选来源；选 YouTube 后，第二步同时显示：

- `Von YouTube-Konto laden`：从 YouTube 账号加载。
- 播放列表 URL 输入框与 `Von URL laden`：粘贴链接加载。

因此，旧记录中“流程只有连接来源账号”的概括不完整。两种入口已看到，但未完成加载、选择目标和下载，不据此断言 URL 模式的全部权限或额度。[入口证据](./原始数据-2026-10-25/TuneMyMusic-start-flow-AX.txt)

落地页宣称输出 CSV/TXT，可转移范围列出 Playlists、Lieblingslieder、Lieblingskünstler。正文也提及歌曲、专辑等选择项；这属于说明文案，不等于已验证每种对象都能从 YouTube 导出。页面未给出 CSV 列名或真实文件样例。
