想了解一个 YouTube 频道，并不一定需要它的 YouTube Studio 权限。每个公开视频都带有标题、发布时间、时长、标签，以及（大多数情况下）播放量、点赞数和评论数。把几百行这样的数据放进电子表格，规律很快就会显现出来。

这篇文章介绍一套只用公开数据完成的频道审计流程。它既适用于你自己的频道（想跳出 Studio 的仪表盘、换个外部视角时），也适用于竞争对手，或者你正在考虑赞助、合作的频道。

## 第 0 步：拿到数据

用本站的工具，有两种获取方式：

- [YouTube 频道分析器](/tools/youtube-channel-analyzer) 会立即给出汇总：上传总数、总时长和平均时长、总播放量和平均播放量、总点赞数、总评论数、互动率，常规视频、Shorts 和直播各自的数量，以及播放量最高的 5 个视频。点击 **下载 CSV** 可以得到逐视频的明细，包含 Video ID、Title、URL、Channel、Duration Seconds、Views、Likes、Comments、Uploaded Time 和 Media Type。
- [导出 YouTube 频道](/tools/export-youtube-channel) 可以生成更完整的文件，支持包括 CSV 和 Excel 在内的 13 种格式。除了统计数据和时长，还包括视频描述、标签、描述里的话题标签、描述里的链接和邮箱，以及缩略图地址。

两个工具都支持输入频道 URL、handle 或频道 ID，通过官方 YouTube Data API 读取频道的公开上传，最多覆盖 5,000 个公开视频，并且都可以只看常规视频、Shorts 或直播。

我一般先用分析器看个大概，再把整个频道导出为 Excel 做下面的细致分析。本文的表格公式使用分析器 CSV 的列号：F 列是 Duration Seconds，G 列是 Views，H 列是 Likes，I 列是 Comments，J 列是 Uploaded Time。如果你的文件布局不同，请相应调整。

## 1. 更新节奏

更新节奏是最容易看、也最能说明问题的信号之一。按 **Uploaded Time** 排序后，重点看：

- **每月上传数量。** 加一个表示月份的辅助列，再按月计数：

```text
=LEFT(J2, 7)
```

它会返回类似 `2026-03` 的值，用数据透视表计数即可。

- **两次上传之间的间隔。** 按从旧到新排序后，距上一个视频的天数为：

```text
=DATEVALUE(LEFT(J3,10)) - DATEVALUE(LEFT(J2,10))
```

- **随时间的变化。** 一个频道从每周一更变成每周三更，或者中断了半年，这些都能反映出它的策略或团队规模的变化。

稍后再把节奏和效果放在一起看：更新变频繁、单个视频播放量却在下滑，和更新变频繁、播放量保持稳定，是两种完全不同的情况。

## 2. Shorts 与长视频的比例

分析器会把上传内容分为常规视频、Shorts 和直播。这个分类是基于规则的推断，值得了解它的原理：

- 带有直播信息的内容（直播回放、预定直播和首播）一律算作**直播**；
- 其余时长不足 60 秒的算作 **Shorts**；
- 剩下的都算作常规**视频**。

公开 API 并没有“这是 Shorts”的标记。而 YouTube 早已允许发布超过一分钟的 Shorts，所以一到三分钟之间的竖屏 Shorts 会被计入常规视频。请把 Shorts 数量看作下限；如果这个比例对你的结论很关键，可以手动核对时长处于临界区间的视频。

比较表现时，一定要在同一类型内部比较。Shorts 和长视频的分发方式、计数方式都不同，混在一起求平均，掩盖的信息比揭示的多。可以使用媒体类型筛选，或者在 CSV 里筛选 Media Type 列。

## 3. 时长分布

单看平均时长很容易被误导：一个频道一半是 30 秒片段、一半是 40 分钟长视频，平均时长约 20 分钟，而它其实从来没有发过 20 分钟的视频。更好的办法是看分布，把秒数分到几个区间：

| 区间        | 秒数范围     |
| ----------- | ------------ |
| 1 分钟以内  | 0–59         |
| 1–4 分钟    | 60–239       |
| 4–10 分钟   | 240–599      |
| 10–20 分钟  | 600–1,199    |
| 20 分钟以上 | 1,200 及以上 |

用 `COUNTIFS` 对时长列计数就很快，例如 `=COUNTIFS(F:F, ">=600", F:F, "<1200")`。接着看看某些时长区间是否持续获得更高的日均播放量（见下文）。很多频道都有一个“主场时长”，表现好的视频大多集中在这个区间。

## 4. 播放、点赞、评论与互动率

分析器给出的互动率按下面的方式计算：

```text
互动率 = （总点赞数 + 总评论数）÷ 总播放量 × 100
```

它可以作为一个快速的健康信号，但在引用之前，你需要了解几点局限。

### 隐藏的点赞数和关闭的评论

创作者可以隐藏点赞数，也可以关闭评论。在分析器的频道汇总里，隐藏或缺失的数值按 0 处理，而该视频的播放量仍然计入分母。因此，部分视频隐藏了点赞数的频道，互动率会显得比实际更低。在 CSV 中这些单元格是空白的，你可以把它们筛掉后重新计算。

### 它按播放量加权

由于公式是用频道总量相除，一个拥有数百万播放的爆款视频会主导整个结果。如果这个视频的点赞比例偏低，整个频道就会显得互动不佳。想要更公平的视角，可以逐个视频计算互动率，再取**中位数**：

```text
=(H2 + I2) / G2
```

然后对这一列取中位数，跳过播放量为 0 的行。

### 老视频有更多时间积累

一个五年前的视频和一个五天前的视频，不能直接比较播放总量。可以用**发布以来的日均播放量**来按时间归一化：

```text
=G2 / MAX(1, TODAY() - DATEVALUE(LEFT(J2,10)))
```

这个指标并不完美，因为大多数视频的播放量集中在发布初期，但用来比较不同视频，远比直接比总量合理。

## 5. 找出爆款和异常视频

分析器会列出播放量最高的 5 个视频，这是一个不错的起点。但“播放最多”往往只意味着“发布早且表现不错”。要找出真正的异常值：

1. 只保留一种媒体类型，最好再限定在最近 12 个月；
2. 计算每个视频的日均播放量；
3. 求出这一组的日均播放量中位数；
4. 用每个视频的日均播放量除以中位数。

达到中位数三倍及以上的视频值得仔细研究。这个阈值只是经验做法，不是行业标准，选一个能把明显赢家区分出来的倍数即可。对每个异常视频，记录它的主题、标题结构、时长和发布日期。表现最差的那 10% 也用同样的方法看一遍——底部的共性同样有价值。

## 6. 关键词与标签规律

视频标签不会显示在 YouTube 播放页上，但它们属于公开元数据。频道导出文件中有 **Tags** 列（导出文件的 C 列），还有 **Tags (in description)** 列，记录描述中写的话题标签。每个单元格是一个带方括号的列表，例如 `[#python, #tutorial]`。

几种简单的用法：

- 统计某个标签出现的次数：`=COUNTIF(C:C, "*#tutorial*")`；
- 对比异常视频和普通视频使用的标签；
- 检查一致性：同一个系列每期是否使用相同的标签？

标题往往比标签更能说明问题。留意重复出现的标题句式（“我试了……”“A 和 B 对比”“盘点 N 个……”）、反复出现的关键词，以及标题风格随时间的变化。如果想看频道在自身设置里填写的频道级关键词，可以用 [YouTube 频道关键词提取工具](/tools/youtube-channel-keywords)。

标签对排名的影响很小，更适合用来理解创作者如何描述自己的内容，而不是当作增长技巧。

## 审计清单

1. 用 [YouTube 频道分析器](/tools/youtube-channel-analyzer) 跑一遍，记下上传数、内容类型比例、互动率和热门视频；
2. [导出频道](/tools/export-youtube-channel) 为 Excel 或 CSV；
3. 按上传时间排序，画出每月上传数，标出断更期；
4. 按媒体类型拆分数据，之后每种类型分别分析；
5. 对时长分区间，找出频道的“主场时长”；
6. 增加日均播放量和单视频互动率两列，计算中位数而不只是平均值；
7. 标记高于中位数设定倍数的异常视频，以及表现最差的 10%；
8. 对比异常视频与其他视频的标题、主题和标签；
9. 写下三到五条假设，例如“15 分钟以上的教程表现优于更短的教程”，并在接下来的更新中验证；
10. 保存导出文件时在文件名中加上日期。一个月后再导出一次，就能得到单次快照无法提供的增长对比。

## 公开数据无法告诉你的事

基于公开数据的审计有明确的边界。下面这些指标只有频道所有者能在 YouTube Studio 中看到：

- **观看时长和平均观看时长。** 播放量很高的视频，观众也可能很快就离开了。
- **观众留存曲线。** 观众在哪里流失，从外部完全看不到。
- **曝光次数和点击率。** 你无法判断一个视频播放量低，是因为很少人看到，还是因为很少人点击。
- **流量来源。** 搜索、推荐、浏览页和外部网站带来的播放，在播放量里看起来都一样。
- **收入、RPM 和 CPM。** 任何公开的“收入估算”都只是根据播放量推测出来的。
- **单个视频带来的订阅数，以及观众画像。**

公开数据也只是快照：它显示的是当前累计值，而不是播放量是如何一步步增长的。这正是定期重复导出的价值所在。

如果你审计的是自己的频道，可以把公开数据审计当作一份快速、便于分享的概览，用来和同类频道在同一口径下比较，再去 YouTube Studio 查看上面那些指标。如果你审计的是别人的频道，请把结论表述为假设，因为最关键的数据你看不到。
