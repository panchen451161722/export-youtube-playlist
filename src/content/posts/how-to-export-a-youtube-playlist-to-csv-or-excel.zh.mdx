电子表格通常是查看较长 YouTube 播放列表最方便的方式。你可以搜索标题、按时长排序、比较公开互动数据，并在不逐个打开视频的情况下保存完整链接列表。

本指南介绍如何把可访问的公开 YouTube 播放列表导出为 CSV 或 Excel，无需安装浏览器扩展，也无需授权访问你的 YouTube 账号。

## 开始之前

你需要一个公开播放列表的 URL。常见格式如下：

```text
https://www.youtube.com/playlist?list=PLxxxxxxxxxxxxxxxx
```

其中的 `list` 参数用于标识播放列表。包含 `list` 参数的普通视频 URL 通常也可以使用。

公共 API 无法读取私密播放列表。已删除、私密、受年龄限制或区域限制的视频可能不会出现在结果中，也可能只提供部分元数据。

## 第一步：复制播放列表 URL

在 YouTube 中打开播放列表，从浏览器地址栏或“分享”菜单复制它的 URL。请确认 URL 包含播放列表的 `list` 参数。

## 第二步：粘贴播放列表 URL

打开[播放列表导出工具](/)，把 URL 粘贴到输入框中。开始导出时，工具会验证 URL，并通过官方 YouTube Data API 请求可用的公开元数据。

整个过程不需要登录 YouTube。导出工具不会请求访问你的订阅列表、观看记录或私密播放列表。

## 第三步：了解导出内容

当前版本支持单个播放列表最多 500 个视频。

导出文件可以包含以下字段：

- 视频标题和视频 URL。
- 简介、缩略图 URL、频道名称和上传时间。
- YouTube 提供时的公开观看、点赞和评论数。
- 以秒、分钟、时间戳和可读文本表示的视频时长。
- 视频标签和话题标签，以及简介中出现的电子邮件地址和链接。

公开数据会随时间变化，因此导出结果是加载播放列表时可用数据的快照。

## 第四步：选择 CSV 或 Excel

选择其中一种格式，或者同时选择两种：

- **[CSV](/tools/export-youtube-playlist-to-csv)** 文件轻量，适合 Google Sheets、数据库导入、脚本和数据分析工具。CSV 工具页提供示例文件和全部 17 列的字段说明。
- **[Excel（.xlsx）](/tools/export-youtube-playlist-to-excel)** 可以保留列宽和简介换行，更适合直接使用 Microsoft Excel 或兼容的电子表格软件查看。Excel 工具页介绍工作簿布局和兼容性。

如果同时选择两种格式，导出工具会下载一个包含两个文件的 ZIP 压缩包。不选择任何格式时，工具会生成包含全部支持格式的 ZIP 文件。

## 第五步：导出并下载

点击**导出**。文件会在浏览器中生成，下载开始时页面会显示成功提示。

下载文件名基于播放列表标题生成。来自外部的表格文本会经过转义处理，以降低打开文件时触发表格公式执行的风险。

## 应该选择哪种格式？

如果你需要便于迁移的纯文本文件，计划用代码处理数据，或者需要把数据导入其他服务，请选择 CSV。如果你更需要格式化工作表，并准备手动查看较长简介或大量列，请选择 Excel。

同时保留两种格式也很实用：Excel 工作簿方便阅读，CSV 源文件则适合以后的自动化处理。

## 常见问题

### 无法加载播放列表

检查 URL 是否包含播放列表 ID，并确认播放列表是公开的。登录本网站也无法让私密播放列表变得可访问，因为导出工具不会请求 YouTube 账号权限。

### 部分视频没有导出

YouTube 可能不会通过 API 返回私密、已删除、受限制或其他不可用的视频。因此，API 返回的数量可能与播放列表所有者看到的数量不同。

### 观看量、点赞或评论为空

部分创作者会关闭公开互动数据，某些视频类型也不会提供全部统计值。空白单元格表示该值不可用，并不代表数值为零。

### API 配额暂时耗尽

工具使用共享的 YouTube API 配额。如果配额已经用完，请等待一段时间后再试，不要连续重复提交同一个播放列表。
