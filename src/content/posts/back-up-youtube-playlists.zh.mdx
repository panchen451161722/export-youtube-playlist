只要维护过几年的播放列表，你多半遇到过这种情况：某个曾经很喜欢的讲座、歌曲或教程，现在只剩一条“已删除的视频”或“私享视频”，缩略图变成灰色，标题也不见了。有时 YouTube 干脆把不可用的视频隐藏起来，只显示一个变小的数量。不管哪种情况，能帮你重新找到这个视频的信息——通常就是标题和频道——都已经从播放列表页面上消失了。

解决办法很朴素，但很有效：定期为你在意的播放列表做一份元数据备份。本文介绍应该保存什么、哪些文件格式值得保留、一个只需几分钟的备份流程，以及如何对比两份备份，准确找出消失了哪些视频。

## 播放列表为什么会丢失信息

播放列表保存的是指向视频的引用，而不是视频的副本。当视频所有者删除视频、把它设为私享，或者视频因政策、版权原因被移除时，这条引用仍然留在你的播放列表里，但 YouTube 不再向你展示该视频的详情。这就是占位条目没有标题的原因。

常见的几种情况：

- **视频被删除。** 上传者删除了视频，或者其频道已被关闭。
- **视频被设为私享。** 上传者修改了公开范围。视频仍然存在，但你已经看不到它，也看不到它的标题。
- **视频被屏蔽或受限。** 视频可能在你所在的地区不可用，或因其他原因无法观看，并可能在播放列表中被隐藏。
- **视频被改名。** 影响没那么大，但创作者经常修改标题，导致以前的笔记或书签很难对上号。

如果你在这些事情发生之前保存了标题和频道名，至少还可以去搜索重新上传的版本、更新的版本，或者这位创作者的其他作品。没有这些信息，就只能靠猜。

## 一份有用的备份应包含什么

以后要认出一个视频，并不需要太多信息。关键字段如下：

- **视频 ID**（位于 `Video url` 中 `v=` 之后）：唯一稳定的标识；标题会变，ID 不会
- **标题**（`Title`）：以后真正用来搜索的内容
- **频道**（`Channel name`）：有助于找到重新上传的版本和创作者的其他视频
- **链接**（`Video url`）：可以用来确认视频是否仍然存在
- **发布日期**（`Uploaded Time`）：用于区分不同版本和重新上传

导出工具会包含以上全部字段，另外还有简介、时长、标签、简介中出现的链接，以及公开的播放、点赞和评论数。简介同样值得保存：里面常常有主讲人姓名、课程编号，或者指向课件的链接，这些信息往往比视频本身存在得更久。

导出文件中没有单独的视频 ID 列，但可以很容易地从链接中提取。在 Google 表格中，假设链接位于 M 列：

```text
=REGEXEXTRACT(M2, "v=([^&]+)")
```

`REGEXEXTRACT` 是 Google 表格的函数。在 Excel 365 中可以改用 `=TEXTAFTER(M2, "v=")`，因为导出的链接在 ID 之后没有其他参数。

## 选择文件格式

[播放列表导出工具](/)支持 CSV、Excel、Text、Bookmark HTML、JSON、Markdown、XML、HTML、YAML、SQLite、Word、M3U 和 M3U8。选择多个格式时会下载一个 ZIP 压缩包；如果一个格式都不勾选，则会下载包含全部格式的压缩包。做备份并不需要所有格式。下面针对“备份”这个具体用途做个比较：

- **CSV** 是最好的默认选择。它是带 BOM 的 UTF-8 纯文本，任何表格软件都能打开，脚本也能读取，几十年后依然可读，并且保留全部 17 列。[CSV 导出工具](/tools/export-youtube-playlist-to-csv)页面提供了一个示例文件，可以先下载看看。
- **JSON** 适合以后用脚本对比备份。每个视频是一个对象，键名与表格列名相同，例如 `"Video url"` 和 `"Channel name"`。
- **Excel（.xlsx）** 最适合人工阅读，表头冻结，简介自动换行。但它是二进制文件，不便于自动对比。建议与 CSV 一起保存，而不是用它代替 CSV。
- **SQLite** 会把所有数据放进一张名为 `videos` 的表，如果你想把多次备份集中存放并用 SQL 查询，会很方便。
- **Bookmark HTML** 只包含标题和链接，但可以直接导入浏览器书签，是一份简单直观的保底备份。
- **Markdown** 和 **Text** 在任何笔记软件里都能阅读，浏览起来很方便，代价是不太适合程序处理。

比较合理的最低配置是 **CSV 加 JSON**。如果想要一份浏览起来更舒服的版本，可以再加上 Excel 或 Bookmark HTML。

## 一套实用的备份流程

### 1. 确定要备份哪些播放列表

列出那些真正丢了会心疼的播放列表：研究资料合集、课程内容、花了多年整理的音乐等。导出工具可以读取公开播放列表和可访问的不公开（unlisted）播放列表；它从不登录你的账号，因此无法读取私享播放列表。如果你自己的某个播放列表是私享的，可以在导出时临时改为“不公开”，导出完成后再改回来。

### 2. 在文件名中加上日期

导出文件以播放列表标题命名，时间一长，同名文件就会互相覆盖或混淆。建议重命名每个文件，让它按日期排序，并能识别出是哪个播放列表：

```text
2026-10-12_ml-lectures_PLxxxxxxxx.csv
2026-10-12_ml-lectures_PLxxxxxxxx.json
```

把播放列表 ID（链接中 `list=` 后面的值）写进文件名很重要，因为 CSV 中保存的是视频行，并不包含播放列表本身的 ID。还需要注意：导出工具生成文件名时只保留拉丁字母、数字、空格、连字符和下划线。如果播放列表标题全部是中文，文件会被命名为 `youtube-playlist`，所以对中文播放列表来说，重命名几乎是必需的。

### 3. 至少存放在两个地方

一份放在电脑上，另一份放在云存储或移动硬盘里。元数据文件体积很小，即使按月备份好几年，也几乎不占空间。

### 4. 按计划重复

对于经常更新的播放列表，每月备份一次就足够了；很少变动的播放列表，每季度一次即可。在你自己整理或删除播放列表内容之前，务必先导出一次。

## 对比两份备份，找出消失的视频

已删除和私享的视频不会出现在新的导出文件中，因为 YouTube Data API 已经不再返回它们的详情。这让对比变得很简单：旧文件中有、新文件中没有的条目，要么已经不可用，要么已被移出播放列表。

对比时请始终使用 `Video url`（或视频 ID），不要用标题，因为标题可能会变。

### 在表格中对比

把旧的导出文件导入名为 `Old` 的工作表，把新的导入名为 `New` 的工作表。在 `Old` 工作表的 R2 单元格输入以下公式并向下填充：

```text
=IF(COUNTIF(New!M:M, M2)=0, "Missing", "")
```

如果想用一个公式直接得到所有消失视频的完整列表：

```text
=FILTER(Old!A2:M, COUNTIF(New!M2:M, Old!M2:M)=0)
```

如果还想发现被改名的视频，可以用 `XLOOKUP` 返回当前标题，找不到时返回标记：

```text
=XLOOKUP(M2, New!M:M, New!A:A, "Missing")
```

把结果放在旧标题旁边，两者不一致的行就是被改过名的视频。以上公式使用的是 Google 表格的区域写法；在 Excel 中，请把 `M2:M` 这样的开放区域换成 `M2:M600` 这样的固定区域。

### 用一条简短的命令对比

如果保存了 JSON，在 macOS 或 Linux 上可以用 `jq` 和 `comm` 列出被移除的链接：

```bash
jq -r '.[]["Video url"]' 2026-09-12_ml-lectures.json | sort > old.txt
jq -r '.[]["Video url"]' 2026-10-12_ml-lectures.json | sort > new.txt
comm -23 old.txt new.txt
```

用 Python 对比 CSV 文件也很简单。这里使用 `utf-8-sig` 编码，以便正确处理 BOM：

```python
import csv

def load(path):
    with open(path, newline="", encoding="utf-8-sig") as f:
        return {row["Video url"]: row for row in csv.DictReader(f)}

old = load("2026-09-12_ml-lectures.csv")
new = load("2026-10-12_ml-lectures.csv")
for url in old.keys() - new.keys():
    print(old[url]["Title"], "|", old[url]["Channel name"], "|", url)
```

输出结果会列出每个消失视频的标题和频道——正是“已删除的视频”占位条目所隐藏的信息。

## 元数据备份做不到什么

有必要把它的局限说清楚：

- **它不会保存视频本身。** 导出文件只包含文本和链接。缩略图字段也只是链接，视频消失后通常会随之失效。导出工具不会下载视频或音频文件，也不打算这样做。
- **它无法恢复 YouTube 已经不再提供的数据。** 如果在导出时视频已经被删除或设为私享，它就不会出现在文件中。备份只有提前做才有用。
- **超大播放列表只能部分覆盖。** 每个播放列表最多读取 500 个可用视频，因此对于很大的播放列表，备份只覆盖前 500 个可用条目。
- **数字只是快照。** 播放、点赞和评论数反映的是导出当天的情况，之后会不断变化。

为了自己查阅而保存标题、频道和链接，是合理的个人记录。但重新上传或传播别人的视频则是另一回事：如果你珍视的某个视频消失了，更尊重创作者的做法是寻找官方重新上传的版本，或者联系创作者本人，而不是去找一份版权方已经选择移除的副本。

每个月花几分钟导出一次，下次播放列表里再出现灰色条目时，你就能清楚地知道它原来是什么。
