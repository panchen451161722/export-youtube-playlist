## 概述

Export YouTube Playlist 可将公开 YouTube 播放列表的元数据转换为 CSV 或 XLSX 文件，也可以复制其中的视频链接。本政策说明您使用服务时涉及的信息及您可以作出的选择。

核心导出功能不要求注册账户。用户可以选择使用 Google 登录，以使用账号功能及未来的付费权益；登录不会授权本服务访问您的 YouTube 账号。我们的应用不会主动建立或保存您提交的播放列表链接以及导出结果历史。

## 导出时处理的信息

当您提交播放列表链接时：

1. 链接会发送到我们的服务器，用于校验并提取播放列表标识符。
2. 服务器通过 YouTube Data API 请求公开的播放列表和视频元数据。
3. 查询结果会返回浏览器供您预览。
4. CSV 与 XLSX 文件在您的浏览器中生成，我们不会将生成的文件再次上传到服务器。

公开元数据可能包括视频标题、链接、频道名称、发布日期、时长、播放量、缩略图和播放列表顺序。私密、不可用或已删除的内容可能无法返回。

本服务不使用 YouTube OAuth，也不会请求访问您的 YouTube 账户。请勿提交私密播放列表链接、登录凭据、API Key 或其他机密信息。

## 存储与技术数据

播放列表链接和 API 返回的元数据只为完成当前请求而处理，不会被主动写入我们的应用数据库。预览内容可能暂时保留在浏览器内存中，直至您刷新或关闭页面。

与大多数网站一样，我们的托管和安全服务商可能会处理提供及保护网站所需的有限技术信息，例如 IP 地址、浏览器类型、时间戳、请求状态和安全事件。相关服务商会根据其自身政策和运营要求处理与保留这些信息。

## YouTube Data API

本服务通过 YouTube Data API 获取公开信息。我们发起 API 请求时，Google 可能接收到播放列表标识符、服务器网络信息和请求所需的技术信息。Google 将根据其自身条款和隐私政策处理相关信息。

Export YouTube Playlist 是独立服务，不受 YouTube 或 Google 认可，也与其不存在隶属关系。

## 账号

如果您选择 Google 登录，我们可能保存运营账号和会话所需的信息，例如姓名、邮箱、头像、账号标识符、会话记录及账号创建或更新时间。我们不会获得您的 Google 密码。

您可以在 Profile 页面删除账号。删除操作会根据数据库关联关系删除账号及相关应用记录。未来推出付费功能后，如法律、安全、防欺诈或交易合规要求保留部分记录，我们可能依法保留。

## Cookie、分析、安全与广告

我们可能使用必要的本地存储或 Cookie 来保存语言、主题等偏好。

Cloudflare 可能通过托管、安全防护、Turnstile 机器人识别和 Cloudflare Web Analytics 处理有限的技术信息及汇总使用数据。Turnstile 会评估技术信号，用于区分正常用户和自动化滥用。

我们使用 Microsoft Clarity，通过汇总交互分析、热图和会话回放了解访客如何使用网站。Clarity 可能处理设备与浏览器信息、页面路径、点击、滚动和导航行为等技术及交互数据。我们已在 Clarity 中遮罩播放列表链接、返回的播放列表或频道详情、账号表单及其他指定结果区域；不会主动将用户提交的链接、视频或播放列表标识符、标题、姓名或邮箱作为自定义分析事件参数发送。

Clarity 在本站永久以无 Cookie 模式运行。分析存储和广告存储始终保持禁用，因此 Clarity 不会使用其第一方或第三方 Cookie 跨页面或跨访问识别访客。无 Cookie 交互数据仍可能被收集，但会话可能被拆分，部分分析功能也可能受限。Microsoft 会依据其自身隐私条款处理 Clarity 数据。

仅当网站完成配置并实际启用后，我们才会使用广告服务（包括 Google AdSense）。启用后，广告服务商可能使用 Cookie 或类似技术投放、个性化或衡量广告；具体处理受其政策及页面向您提供的同意选项约束。您也可以通过浏览器设置管理 Cookie。
