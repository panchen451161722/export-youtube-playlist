## 概述

Playlist Expoter 提供公开元数据工具及需登录的播放列表备份工作区。公开工具处理您提交的链接，供预览或浏览器导出。在播放列表备份中创建收藏会保存其来源、设置和元数据快照，供您查看变化和导出记录。

本服务使用 YouTube API Services。YouTube 和 Google 根据 [Google 隐私政策](https://policies.google.com/privacy)及 [YouTube 服务条款](https://www.youtube.com/t/terms)处理信息。本服务独立运营，不受 YouTube 或 Google 认可，也与其不存在隶属关系。

## 公开工具与浏览器导出

服务器校验您提交的公开视频、播放列表或频道链接，通过 YouTube Data API 查询可用元数据，再返回浏览器。元数据可能包括标识符、标题、链接、频道名称、发布日期、时长、播放量、缩略图和播放列表顺序。

除非您另外使用播放列表备份，公开工具不会创建已保存收藏或应用层面的导出历史。下载文件在浏览器中生成，不会再次上传至服务器。预览可能保留在浏览器内存中，直至刷新或关闭页面。托管和安全服务商仍可能处理技术请求信息。

我们不下载或存储 YouTube 视频、音频文件。元数据导出无法恢复已从 YouTube 移除的内容。

## 网站账号与独立 YouTube 授权

登录网站与连接 YouTube 是独立选择。Google 登录提供网站账号和会话所需的身份信息，例如姓名、邮箱、头像和账号标识符。我们也保存运营和保护账号所需的账号及会话记录和时间戳。我们不会获得您的 Google 密码。

点击 **连接账户** 会请求 `https://www.googleapis.com/auth/youtube.readonly`，允许读取已连接 YouTube 频道的信息及您选择的来源：有权访问的私有播放列表、喜欢的视频和已订阅频道。“喜欢的音乐”是对已点赞 YouTube 视频按 Music 分类筛选，并非完整 YouTube Music 资料库，也可能与其喜欢的音乐列表不同。本服务不支持“稍后观看”。

我们保存已连接频道的标识符、标题、缩略图引用、连接状态、授权时间戳，以及授权请求所需的 OAuth 凭据。专用于 YouTube 连接的凭据会在存储前加密；这不表示所有账号数据或每个身份服务商字段均经过应用层加密。

离线授权允许服务器为您启用的功能刷新访问权限。自动检查仅在调度已启用、收藏已启用且具有有效使用权益时运行。该权限不允许修改播放列表、点赞、订阅，或上传、删除视频。

## 保存的收藏与可选通知

播放列表备份保存收藏来源及适用的链接、所选连接、名称、检查频率、通知选择、检查时间戳、近期快照和检测为缺失条目的元数据。这些记录关联到您的网站账号，不向其他用户公开，用于显示、比较、检查及 CSV、Excel 或 JSON 导出。每次检查目前最多支持 500 个来源条目，在下述保存期限内最多保留五份近期快照。

历史快照是带日期的记录，不代表 YouTube 当前内容。无法获取的元数据不能可靠备份。

邮件提醒和 JSON 备份投递需要已配置的投递服务、您启用相关偏好以及已验证的收件邮箱。启用后，所选服务商（Resend 或 Cloudflare Email Service）处理收件地址和通知内容，可能包括收藏元数据、变更详情及 JSON 快照附件。手动检查不会发送这些定时通知。已投递邮件的副本由您和您的邮件服务商管理。

## Google 用户数据的用途与共享

我们使用 Google 和 YouTube 用户数据提供上述账号、收藏、检查、导出及可选通知功能，并在安全和法律义务需要的范围内处理数据。我们对 Google API 数据的处理遵守 [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy)，包括 Limited Use（受限使用）要求。

我们不出售 Google 或 YouTube 用户数据，不用于广告、信用决策或训练通用人工智能及机器学习模型，不向广告平台或会话回放分析服务传输私有收藏内容。除非您同意针对特定内容进行支持调查、出于安全或滥用调查需要，或法律要求，否则工作人员不会读取这些内容。

Google 接收登录、授权、数据查询及撤销所需的请求。托管和数据库服务商为运营服务处理数据；已启用的邮件服务商处理上述通知数据。共享仅限于所请求功能、安全或适用法律要求，不会为处理订阅付款而向支付服务商发送收藏导出内容。

## 保存期限、断开连接与删除数据

快照和缺失记录中的 YouTube API 元数据自获取起保存不超过 30 天。新的查询可建立新的当前记录，但不会延长旧快照的期限。暂停收藏或订阅结束不会暂停该期限。过期元数据不再显示或供导出，并由清理任务移除。您自行提供的收藏设置可在收藏存在期间保留，以便之后恢复检查。

- **移除收藏：**从活动应用数据库中删除其已保存元数据及相关待投递通知数据，并停止检查；YouTube 上的来源保持不变。
- **断开 YouTube 账户：**经您确认后，停止通过该连接访问数据，并从活动应用数据库中删除连接账号资料、关联私有收藏、快照、缺失记录和待投递通知数据，同时向 Google 请求撤销授权。删除无法撤销，重新连接不会恢复已删除快照。
- **删除网站账号：** 在 **设置 → 个人资料** 中的操作会从活动应用数据库中删除账号、会话及关联收藏数据，并请求撤销其所有 YouTube 连接授权。账单、安全或法律要求的记录仅在这些独立用途必要时保留。
- **在 Google 撤销：**可通过 [Google 账号权限](https://security.google.com/settings/security/permissions)移除访问权限。后台独立于收藏频率，每天安排授权核验；维护任务确认授权已撤销后删除关联数据。如果无法重新确认授权，最迟在上次成功验证后 30 天停止访问并删除关联数据。

本地移除不会等待 Google 的响应。如果撤销请求暂时失败，单独的队列可能保留重试所需的最少加密凭据，最长七天。该凭据只用于撤销，不用于读取 YouTube 数据，完成或到期后删除。撤销可能影响共享同一授权的其他频道或 Google 功能，这些功能可能需要重新连接。

您也可通过 [support@exportyoutubeplaylist.com](mailto:support@exportyoutubeplaylist.com)请求删除。确认账号归属后，我们会尽快且在七个自然日内删除相关 YouTube 数据。我们不会索取 Google 密码或 OAuth token。

这些控制从活动应用存储中移除数据，不能远程删除您的下载文件、已投递邮件或 Google 原始数据。托管服务商的恢复副本和技术日志有独立运营保存周期，我们不承诺这些副本均可立即擦除。如请求也涉及这些记录，请联系我们。

## Cookie、分析、安全与广告

必要的 Cookie 和本地存储支持会话、身份验证、语言、主题及安全。Cloudflare 等基础设施服务商可能处理 IP 地址、浏览器信息、时间戳和安全事件。Turnstile 启用后会评估技术信号，以防止自动化滥用。

未登录时公开页面的可选分析可能包括 Microsoft Clarity、Cloudflare Web Analytics 或其他已配置服务。Clarity 配置为不使用分析或广告 Cookie，但仍可处理页面路径、点击和滚动。账号、身份验证、收藏和备份页面，以及向已登录用户提供的公开页面，不加载第三方分析、会话回放、广告或客服脚本。使用公开页面回放时，提交的链接及公开结果区域会被遮罩；我们不会主动将来源标识符、标题或账号资料作为自定义分析事件参数。

包括 Google AdSense 在内的广告仅在配置并启用的位置运行。服务商可按适用地区的同意选择使用 Cookie、网络信标、IP 地址或类似标识符。授权取得的 Google 用户数据不用于广告。请参阅 [Google 的合作网站信息说明](https://policies.google.com/technologies/partner-sites)、[Google 广告设置](https://adssettings.google.com/)和浏览器控制。在 Google 要求认证同意管理平台的地区，必须等所需同意流程可用后才启用广告。

## 支付

付费方案启用时，结账和订阅管理由页面告知的支付服务商处理，目前播放列表备份使用 Stripe。服务商按其政策处理付款信息。本站保存使用权益及账单所需的账号和交易引用、方案、订阅状态、账单日期和相关记录，不接收或存储完整银行卡号。可购买价格及计费条件在购买前展示。

## 安全、权利与政策变更

我们使用访问控制和技术措施，但任何互联网服务都无法保证绝对安全。根据适用法律，您可对我们持有的个人信息提出访问、更正、删除或其他权利请求。处理前可能需要核实账号归属。

本服务不面向低于其所在国家要求父母同意年龄的儿童。如您认为儿童通过本服务提供了个人信息，请联系我们。

服务或数据处理方式改变时，我们会更新本政策。页面日期表示此版本。对 Google 用户数据的新用途，会在开始前进行相应告知并取得同意。
