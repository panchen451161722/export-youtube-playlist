## 会导出哪些内容

频道导出工具会把一个频道的公开上传视频整理成文件，方便你保存、搜索，或导入其他软件。它通过官方 YouTube Data API v3 读取频道的上传列表，以每批 50 个的方式获取每个视频的完整信息，然后直接在你的浏览器里生成你选择的文件。

你可以用以下任意方式指定频道：

- 频道网址，例如 `https://www.youtube.com/@handle` 或 `https://www.youtube.com/channel/UC...`
- 单独的 handle（`@handle`），或以 `UC` 开头的频道 ID
- 旧式的 `/user/` 网址
- 该频道任意一个视频的网址，我们会自动找到它所属的频道

较早的 `/c/` 自定义网址会被当作 handle 查询。如果查不到，请改用 `@handle` 或视频链接。

导出前先选择 **内容类型**：全部上传、视频、Shorts 或直播。筛选是在上传列表加载完成之后进行的，因此它只会缩小文件范围，不会改变读取了哪些上传视频。

## 17 个字段

所有格式都包含相同的字段，顺序如下：

| 字段                    | 内容                                      |
| ----------------------- | ----------------------------------------- |
| Title                   | 视频标题                                  |
| Description             | 完整的描述文字                            |
| Thumbnail url           | 可用的最大尺寸缩略图                      |
| Channel name            | 频道显示名称                              |
| Views、Likes、Comments  | 导出时的公开数据；被隐藏时留空            |
| Duration in seconds     | 整数秒，例如 `754`                        |
| Duration in minutes     | 保留两位小数的分钟数，例如 `12.57`        |
| Duration in timestamp   | `M:SS` 或 `H:MM:SS`，例如 `12:34`         |
| Duration                | 可读文本，例如 `12 Minutes, 34 Seconds`   |
| Uploaded Time           | UTC 发布时间，例如 `2025-03-14T15:00:00`  |
| Video url               | 标准的 `watch?v=` 链接                    |
| Tags                    | 创作者设置的标签，格式为 `[#tag1, #tag2]` |
| Tags (in description)   | 描述中出现的话题标签                      |
| Emails (in description) | 描述中出现的邮箱地址                      |
| Links (in description)  | 描述中出现的网址                          |

最后三列是对描述文字做模式匹配得到的，并不是 YouTube 提供的结构化数据。重复项会被去掉，但凡是看起来像邮箱或链接的内容都会被收录。

## 13 种格式

| 格式          | 文件                             | 适合用途                               |
| ------------- | -------------------------------- | -------------------------------------- |
| CSV           | `.csv`，带 BOM 的 UTF-8          | 表格软件、Airtable、Notion 导入        |
| Excel         | `.xlsx`，表头加粗并冻结          | 直接在 Excel 中查看，无需导入步骤      |
| Text          | `.txt`，每个视频一段             | 阅读或用 grep 搜索                     |
| Bookmark HTML | 浏览器书签格式的 `.html`         | 把所有视频作为一个书签文件夹导入浏览器 |
| JSON          | `.json`，对象数组                | 脚本和数据处理流程                     |
| Markdown      | `.md`，每个视频一节              | 笔记软件和知识库                       |
| XML           | `.xml`，每个视频一个 item        | 只接受 XML 的旧工具                    |
| HTML          | `_Export.html`，带样式的表格     | 分享一个可直接阅读的页面               |
| YAML          | `.yaml`                          | 配置文件或静态网站工作流               |
| SQLite        | 含 `videos` 表的 `.sqlite`       | 对大型视频目录做 SQL 查询              |
| Word          | `.docx`，每个视频一页            | 打印或作为文档编辑                     |
| M3U / M3U8    | 包含视频链接和时长的播放列表文件 | 能打开 YouTube 链接的媒体播放器        |

只选一种格式，就会直接下载这一个文件；选择多种格式，会打包成一个以频道名命名的 ZIP；一种都不选，则 13 种格式全部打包进 ZIP。

## 实例演示：备份一个频道

_以下为示例，频道和数字均为虚构，仅用于演示操作流程。_

一个有 1,240 个公开视频的小型教育频道，打算在重新整理播放列表之前，先把整个视频目录（包括描述）离线保存一份。

1. 粘贴 `https://www.youtube.com/@example-channel`，内容类型保持 **全部上传**，勾选 **CSV**、**JSON** 和 **SQLite**。
2. 点击 **导出频道**。工具加载上传列表后会自动开始下载：一个包含三个文件的 ZIP。
3. 结果区域显示 **数量: 1240**。把它和频道主页上的视频数对比，一致就说明没有被截断。
4. 把 **排序** 改为 **最早优先**，再点击 **下载所选格式**，即可得到按时间顺序排列的第二份副本。这一步是用浏览器里已有的数据重新生成文件，不会再次请求 YouTube。

拿到 SQLite 文件后可以马上开始查询。所有列都以文本形式存储，列名取自字段名（非字母数字字符会变成下划线），所以排序前要先把数字转换类型：

```sql
SELECT Title, CAST(Views AS INTEGER) AS views, Uploaded_Time
FROM videos
ORDER BY views DESC
LIMIT 10;
```

被隐藏的数据以空字符串存储，转换后会变成 0，计算平均值时记得先把它们过滤掉。

## 最常见的几种用法

- **备份视频目录。** 创作者定期保存一份带日期的标题、描述和标签副本。即使某个视频被删除，文字记录依然保留。
- **检查视频描述。** 在 CSV 中按 Links (in description) 列排序，就能在几百个视频里找出失效的推广链接、旧的社交账号，或需要统一更新的赞助商网址。
- **研究数据集。** JSON 或 SQLite 可以直接作为脚本的输入，用来研究整个频道的标题、标签、发布时间或视频时长。
- **便于浏览的清单。** Bookmark HTML 能把整个目录导入浏览器书签文件夹；M3U 则带着标题和时长列出所有视频，供能打开 YouTube 链接的播放器使用。

## 使用文件之前需要了解的事

- **最多 5,000 个上传视频。** 导出工具最多读取最近的 5,000 个上传视频，顺序与 YouTube 返回上传列表的顺序一致，通常是最新的在前。页面不会单独提示截断，请把"数量"与频道的视频总数对比。
- **只包含公开视频。** 私密视频和被 YouTube 删除的视频不在公开上传列表中，因此不会出现。
- **统计数据是快照，** 记录的是数据加载那一刻的数值。为了减少重复的 API 调用，服务器可能会在几分钟内复用同一频道的数据，所以紧接着再运行一次，数字可能完全相同。
- **Shorts 按时长判断。** 不是直播、且时长不足 60 秒的视频会被标记为 Shorts。超过 60 秒的 Shorts 会被算作"视频"，而普通的一分钟以内短片会被算作 Shorts。凡是带有直播信息的内容（包括已预约的直播）都会被标记为"直播"。
- **公式保护。** 在 CSV 和 Excel 中，以 `=`、`+`、`-` 或 `@` 开头的文字会被加上前导撇号，防止表格软件把它当作公式执行。
- **文件名。** 只保留频道名中的英文字母、数字和连字符。如果频道名全是中文，文件名会退回为 `youtube-channel`。

## 常见问题排查

| 现象                                           | 可能原因                                                           | 解决方法                                           |
| ---------------------------------------------- | ------------------------------------------------------------------ | -------------------------------------------------- |
| "无法加载该频道，请检查网址或 handle 后重试。" | handle 拼写错误、无法识别的 `/c/` 名称，或两次请求间隔不到约两秒。 | 稍等片刻，然后改用 `@handle`、频道 ID 或视频网址。 |
| 提示 YouTube API 配额暂时用完                  | 网站共享的每日配额已用完。                                         | 稍后再试。                                         |
| 提示 YouTube 响应时间过长                      | 视频非常多的频道在约两分钟内没有加载完成。                         | 重试，或使用内容类型筛选分批导出。                 |
| 数量为 0                                       | 所选内容类型下没有匹配的上传视频。                                 | 切换到"全部上传"。                                 |
| 数量少于频道总数                               | 5,000 个上限，或存在私密、已删除的视频。                           | 属于正常情况，见上文说明。                         |
