## 频道分析器会给出哪些数据

YouTube 频道分析器把一个频道的公开上传视频汇总在一个页面里。它接受频道网址、`@handle`、频道 ID，或该频道任意一个视频的链接，通过官方 YouTube Data API v3 读取频道的上传列表，再对已加载的上传视频汇总时长和公开统计数据。页面顶部会显示频道名称、handle、频道 ID，以及频道填写了的国家或地区。

每项数据的计算方式如下：

| 指标                 | 计算方式                                                                     |
| -------------------- | ---------------------------------------------------------------------------- |
| 上传数               | 经过内容类型筛选后参与分析的上传视频数量                                     |
| 总时长               | 所有上传视频时长之和，格式为 `H:MM:SS`（小时数可以超过 24，例如 `61:16:00`） |
| 平均时长             | 总时长除以提供了时长的上传视频数量                                           |
| 总播放量             | 公开播放量之和                                                               |
| 平均播放量           | 总播放量除以**全部**参与分析的上传视频数量                                   |
| 总点赞数 / 总评论数  | 公开点赞数和评论数之和                                                       |
| 互动率               | （总点赞数 + 总评论数）÷ 总播放量 × 100，保留两位小数                        |
| 视频 / Shorts / 直播 | 参与分析的上传视频中各类型的数量                                             |
| 热门视频             | 播放量最高的五个上传视频                                                     |

有两点让它和 [播放列表分析器](/tools/youtube-playlist-analyzer) 的表现不同。第一，被隐藏的播放量、点赞数或评论数在合计中按 0 处理，而且平均播放量是除以所有上传视频，而不仅仅是公开了播放量的视频。第二，互动率是频道整体合计之比，因此它实际上是按播放量加权的：一个千万播放的视频对它的影响，远远大于五十个只有几千播放的视频。

## Shorts、视频和直播是怎么区分的

每个上传视频的类型按一条简单规则判断：

1. 如果视频带有直播信息（实际开播时间或预约开播时间），或者正在直播，就归为 **直播**。
2. 否则，如果时长不足 60 秒，就归为 **Shorts**。
3. 其余都归为 **视频**。

YouTube Data API 并没有提供"这是一个 Shorts"的标记，所以时长是最实用的判断依据。对大多数频道来说这条规则是准确的，但它有两个盲区：时长在一到三分钟之间的 Shorts 会被算作"视频"，而不足一分钟的普通横屏短片会被算作 Shorts。如果某个频道大量发布 60 到 180 秒的 Shorts，解读时要留意这一点。

输入框旁边的 **内容类型** 选择器（全部上传、视频、Shorts、直播）会在计算任何指标之前先筛选上传视频。选择 Shorts 时，所有卡片都只描述 Shorts，"视频"和"直播"两项自然显示为 0。

## 实例演示：Shorts 与长视频对比

_以下为示例，频道和所有数字均为虚构，仅用于说明如何解读结果。_

一个美食频道既发长篇菜谱视频，也发快节奏的 Shorts，偶尔还做直播问答。创作者想知道 Shorts 到底有没有发挥作用。按每种内容类型分别运行一次分析器，得到：

| 运行     | 上传数 | 总播放量  | 平均播放量 | 互动率 |
| -------- | ------ | --------- | ---------- | ------ |
| 全部上传 | 312    | 9,840,000 | 31,538.5   | 3.39%  |
| 视频     | 180    | 6,300,000 | 35,000     | 3.67%  |
| Shorts   | 120    | 3,180,000 | 26,500     | 2.83%  |
| 直播     | 12     | 360,000   | 30,000     | 3.50%  |

"全部上传"这次运行还显示总时长为 `61:16:00`，平均时长为 `0:11:47`。

怎么解读：

- Shorts 占上传数量的 38%，却只贡献了约 32% 的播放量，而且每次播放带来的点赞和评论更少。这很常见，因为 Shorts 是在信息流里刷到的，观众很少留言。
- "视频"的互动率最高，说明愿意点进完整菜谱的观众投入度最高。
- 12 场直播占了 61 小时总内容中的约 18 小时，所以全部上传的平均时长看起来比一条普通菜谱视频要长。

这些数据都不能衡量观看时长或收入，那些只有频道所有者能在 YouTube Studio 里看到。但它能告诉你公众的注意力和可见的互动流向了哪里。

## 使用场景

- **对比内容形式。** 像上面那样按内容类型分别运行，比较 Shorts、长视频和直播的表现。
- **检查更新节奏。** 下载 CSV，按 `Uploaded Time` 列统计每月上传数量。用数据透视表或柱状图，空档期和集中发布期一目了然。
- **对标同类频道。** 每个视频的平均播放量和互动率能让不同年龄的频道大致可比；只看总播放量会偏向老频道。
- **合作前了解频道。** 前五个热门视频和类型分布能看出这个频道以什么内容见长，以及直播的频率。

## 逐个视频的 CSV

**下载 CSV** 会为每个参与分析的上传视频保存一行：

```text
Index, Video ID, Title, URL, Channel, Duration Seconds, Views, Likes, Comments, Uploaded Time, Media Type
```

`Media Type` 的取值为 `videos`、`shorts` 或 `live`，判断规则与上文相同。被隐藏的数据会留空。在表格软件里有两个公式值得加上：

```text
L2: =LEFT(J2,7)                     上传月份，例如 2026-04
M2: =IF(G2>0,(H2+I2)/G2,"")         单个视频的互动率
```

对 L 列做数据透视即可得到每月上传数。M 列的中位数比频道整体互动率更能代表"一个典型视频"的水平，因为它不会被少数爆款视频主导。

## 解读数据时的常见误区

- **隐藏点赞和关闭评论会拉低互动率。** 这些视频的播放量照样计入，但点赞或评论按 0 计算。面向儿童、评论被关闭的频道，看起来会比实际更"冷清"。
- **老视频积累的时间更长。** 2019 年的视频已经积累了好几年播放量，上周的新视频还没有。比较近期表现时，先在 CSV 里按日期筛选。
- **统计数据是快照，** 记录的是数据加载那一刻的数值。服务器可能会在几分钟内复用同一频道的数据，以避免重复调用 API。
- **直播评论不等于聊天室消息。** 评论数只包括普通评论，不包括直播过程中的聊天消息。
- **订阅数不参与计算。** 这里的互动率是按播放量计算的，而不是按订阅人数。

## 使用限制

- 分析器最多覆盖 **最近的 5,000 个上传视频**。对于更大的频道，所有指标描述的都是这部分最近的内容，而且页面不会单独提示，请把"上传数"与频道总视频数对比。
- 只包含公开上传的视频；私密视频和已删除的视频不在公开上传列表中。
- 点踩数、观看时长、曝光次数和观众留存率都无法通过公开 API 获取，因此不会显示。

## 常见问题排查

| 现象                                           | 可能原因                                                           | 解决方法                                         |
| ---------------------------------------------- | ------------------------------------------------------------------ | ------------------------------------------------ |
| "无法加载该频道，请检查网址或 handle 后重试。" | handle 拼写错误、旧式 `/c/` 网址无法解析，或两次运行间隔不到约两秒 | 稍等片刻，改用 `@handle`、频道 ID 或视频链接重试 |
| 提示 YouTube API 配额用完                      | 网站共享的每日配额已用完                                           | 稍后再试                                         |
| 提示 YouTube 响应时间过长                      | 视频非常多的频道在约两分钟内没有加载完成                           | 重试；一次只分析一种内容类型可能会有帮助         |
| 所有卡片都显示 0                               | 所选内容类型下没有上传视频                                         | 切换到"全部上传"                                 |
