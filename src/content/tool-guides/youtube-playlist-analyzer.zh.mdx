## 分析器到底在算什么

在决定要不要开始看一个播放列表之前，YouTube 播放列表分析器帮你回答一个问题：这个列表到底有多大？你粘贴播放列表网址后，我们通过官方的 YouTube Data API v3 读取播放列表，再逐个查询其中每个视频的时长和公开统计数据。整个过程不抓取 YouTube 网页，也不需要你登录账号。

所有数字都来自 API 实际返回的视频。下面是每张卡片的计算方式：

| 卡片                  | 计算方式                                                 |
| --------------------- | -------------------------------------------------------- |
| 可用视频              | API 返回了完整信息的视频数量，已删除和私密的条目不计入。 |
| 总时长                | 所有能提供时长的视频的时长之和。                         |
| 平均时长              | 总时长除以提供了时长的视频数量。                         |
| 不同频道              | 返回视频中不重复的频道名称数量。                         |
| 总播放量 / 平均播放量 | 播放量之和，以及该总和除以提供了播放量的视频数量。       |
| 总点赞数 / 平均点赞数 | 同样的方法，只统计公开了点赞数的视频。                   |
| 总评论数 / 平均评论数 | 同样的方法，只统计公开了评论数的视频。                   |

每个总数和平均数下方都有一行类似"基于 36/38 个视频"的说明，表示实际参与计算的视频数量。如果创作者隐藏了点赞数或关闭了评论，这个视频会被排除在该项计算之外，而不是按 0 计算，所以个别隐藏的数据不会把平均值拉低。

摘要下方还有三个区块：

- **预计观看时间**：分别显示正常速度下的总时长，以及总时长除以 1.25、1.5 和 2 的结果。这只是简单的除法，不包括广告、暂停和回看的时间。
- **时长亮点**：列出最长和最短的视频，并附上所属频道和时长。
- **播放量最高的视频**列出当前播放量排名前五的视频；**主要频道**列出贡献视频最多的五个频道，数量相同时按名称字母顺序排列。

时长以 `HH:MM:SS` 格式显示，例如 14.5 小时的播放列表会显示为 `14:30:00`。

## 分析 CSV 文件

点击 **下载分析 CSV** 会为每个已分析的视频保存一行，包含以下列：

```text
Index, Video ID, Title, URL, Channel, Duration Seconds, Views, Likes, Comments, Uploaded Time
```

`Duration Seconds` 是纯整数，方便求和或画图。缺失的播放量、点赞数或评论数会留空，而不是写成 0。`Uploaded Time` 是视频在 YouTube 上的发布时间（UTC，去掉了末尾的 `Z`），不是它被加入播放列表的时间。文件采用带 BOM 的 UTF-8 编码，用 Excel 打开时中文等各种语言的标题都能正常显示。以 `=`、`+`、`-` 或 `@` 开头的标题会被加上一个前导撇号，防止表格软件把它当成公式执行。

需要注意的是，CSV 文件名只保留播放列表标题中的英文字母、数字和连字符；如果标题全是中文，文件名会退回为通用名称 `youtube-playlist-analysis.csv`。

如果你需要描述、标签、缩略图或其他文件格式，请改用 [播放列表 CSV 导出工具](/tools/export-youtube-playlist-to-csv)；分析 CSV 刻意只保留了分析所需的列。

## 实例演示：规划一个课程播放列表

_以下为示例，数字是为了说明如何解读结果而虚构的，并不对应任何真实的播放列表。_

假设你找到了一个有 40 个条目的编程课程，想知道一个月内能不能学完。YouTube 页面显示 40 个视频，但分析器报告只有 38 个可用视频：自播放列表创建以来，有两节课被删除或设为私密。摘要如下：

| 指标     | 数值                          |
| -------- | ----------------------------- |
| 可用视频 | 38                            |
| 总时长   | 14:25:00（基于 38/38 个视频） |
| 平均时长 | 00:22:46                      |
| 不同频道 | 3                             |
| 总点赞数 | 基于 36/38 个视频             |
| 总评论数 | 基于 35/38 个视频             |

预计观看时间区块：

| 速度       | 预计时间 |
| ---------- | -------- |
| 正常速度   | 14:25:00 |
| 1.25× 倍速 | 11:32:00 |
| 1.5× 倍速  | 09:36:40 |
| 2× 倍速    | 07:12:30 |

按 1.5 倍速、每天 45 分钟计算，大约需要 13 次学习，一个月内完全来得及。"不同频道：3"说明这是一个合辑而非同一位讲师的系列课，风格可能会有差异。"36/38"只是说明有两个视频隐藏了点赞数，并不是出错。

想做学习计划的话，可以在表格软件中打开 CSV，在 K 列添加一个按 1.5 倍速换算成小时的累计值：

```text
K2: =SUM($F$2:F2)/1.5/3600
```

向下填充后，每当数值跨过 0.75 的整数倍（即 45 分钟），就是一个自然的分段点。

## 其他常见用法

- **出行前检查待看列表。** 把想看的视频收集到一个公开或不公开（unlisted）的播放列表里，看看按 1.25 倍速能否在一趟航班内看完。
- **整理教学播放列表。** 老师可以用"时长亮点"找出夹在 10 分钟短片中的 2 小时讲座，用"主要频道"确认没有某一个来源占比过大。
- **审视合作或音乐播放列表。** "播放量最高的视频"能看出哪些条目撑起了整个列表，"不同频道"则反映内容是否多样。
- **比较同一课程的两个版本。** 分别分析两个播放列表，对比总时长和平均时长，再决定选哪一个。

## 正确解读结果

- **统计数据是快照。** 播放量、点赞数和评论数是你点击"分析播放列表"那一刻的数值，明天再运行一次，数字就会变化。
- **视频数可能少于 YouTube 显示的数量。** 已删除、私密或其他不可用的条目会被直接跳过。YouTube 显示的数量与"可用视频"之差，就是失效条目的数量。
- **"暂无数据"不等于 0。** 只有当播放列表中没有任何视频公开该项统计时才会出现。
- **"不同频道"按名称计数。** 两个显示名称完全相同的不同频道会被算作一个。
- **直播可能没有时长。** 正在直播或已预约的直播可能还没有时长信息，因此不计入时长合计，"基于"说明行会体现这一点。

## 使用限制

- 每个播放列表最多读取 **500 个可用视频**。更长的播放列表会显示"当前显示前 500 个可用视频"的提示，所有数字都只覆盖这 500 个视频。
- 只能读取公开的播放列表，以及你拥有链接的不公开播放列表。私密播放列表、"稍后观看"和"赞过的视频"都绑定在账号上，无法通过公开 API 密钥访问。
- YouTube 自动生成的"合辑"（Mix）播放列表通常也无法通过 API 读取。
- 所有访客共享同一份每日 YouTube API 配额，访问量特别大的日子里工具可能会暂时无法响应。

## 常见问题排查

| 提示或现象                                                    | 可能原因                                                                   | 解决方法                                                     |
| ------------------------------------------------------------- | -------------------------------------------------------------------------- | ------------------------------------------------------------ |
| "请输入包含 list ID 的有效 YouTube 播放列表网址。"            | 链接中没有 `list=` 参数、不是 YouTube 地址，或 ID 太短（例如 `list=WL`）。 | 打开播放列表本身复制网址，或使用仍带有 `&list=` 的视频链接。 |
| "此播放列表为私密、已删除，或无法通过公开 YouTube API 访问。" | 播放列表为私密、已删除或仅限账号访问。                                     | 请所有者将其设为公开或不公开后重试。                         |
| "YouTube API 限额暂时用完，请稍后重试。"                      | 共享的每日配额已用完。                                                     | 稍后再试，配额每天重置。                                     |
| "YouTube 响应时间过长，请重试。"                              | API 约 15 秒内没有响应。                                                   | 重试即可，较大的播放列表偶尔需要第二次尝试。                 |
| "请稍等片刻后再加载另一个播放列表。"                          | 两次运行间隔不到约两秒。                                                   | 等几秒钟再点击。                                             |
| "此播放列表没有可用的公开视频。"                              | 所有条目都已删除或设为私密。                                               | 到 YouTube 上检查该播放列表。                                |
